---
name: CHESS editor audience
description: Editing experience expectations for staff who maintain the Colorado Heritage website.
---

Make everyday site editing visual and straightforward for staff who are not comfortable with Markdown. Keep advanced source editing available as an optional path for technically capable editors.

**Why:** the user said the people editing the website know basically nothing about Markdown and asked for a Google Sites-like experience with advanced access available.

**How to apply:** use plain-language labels, visual text editing, and form-based controls by default; keep source editing clearly optional. Preserve the existing approved-editor access checks.
